# CARMEN / OPERA

*An Instrument for Poetic Composition*

CARMEN / OPERAは、言葉の収集・探究・操作をテーマとしたブラウザベースの制作環境です。メモ、詩、小説、歌詞などの一般的な文章制作に加え、台本、脚本、戯曲、オペラのリブレットからグリモワールまで、さまざまなジャンルに対応した編集機能を備えています。

Created by Majyutsudo · Version 2.8.64

## 主な機能

- **Writing & Composition** — 作品をブロック単位で執筆・編集。Preview、Focus、構造編集、登場人物登録、書式プリセット。作品集の作成・読み込み。
- **Dictionary & Rhyme** — 日本語・英語の内蔵辞書。言葉を集めるためのRhyme Book、Word Harvester、韻検索ツールRhyme Finder、Anagram Finder、Palindrome Maker。
- **Word Oracle** — 偶然性を取り入れた言語によるオラクル機能。
- **Symbol Keyboard** — Rune、占星術、各種象徴記号の入力。パネル内に文字列を蓄積し、コピーして他のアプリに貼り付けられます。
- **保存と管理** — 作品・作品集の `.carmen` 形式での入出力、全体データのバックアップ。Rhyme Bookの辞書セット管理とCSV入出力。

## 使い方

公開されたGitHub Pagesのウェブサイトをブラウザーで開いて使用します。公開URLはデプロイ後に記載します。付属の `index.html` を直接開くこともできますが、PWAやサービスワーカーによるオフライン利用にはHTTPSまたはlocalhostが必要です。

## データの保存とプライバシー

アカウント登録は不要です。作品や個人辞書は基本的に使用中のブラウザー内に保存され、GitHubや開発者へ自動送信されません。異なる端末・ブラウザー間の自動同期はありません。

**大切な作品と辞書は定期的に外部ファイルへバックアップしてください。** ブラウザーデータの削除、プライベートブラウズ、端末の故障などによってデータが失われる場合があります。ローカルファイル版から公開サイトへ移行する際も、書き出しと読み込みが必要です。

対応ブラウザーでは、初回のオンライン読み込み後にオフライン利用できる場合があります。利用可否はキャッシュの保持状況などに依存します。

## v2.8.64 — StructureのCut

- **Cut**：選択範囲の独立ブロックを改行単位で切断し、順序を維持します。
- **Cut-up**：同じ切断の後、断片をまとめてシャッフルします。
- **Shuffle / Reverse**：構成単位の並べ替え。**Join**：選択範囲の独立ブロックを1ブロックに連結。
- CutとCut-upでは空行を除外し、Ensemble・参照ブロックは切断しません。実行前の確認と版の保存を推奨します。


## v2.8.64 — Divider
- Writeのブロック種別にDividerを追加。実線・破線・点線・二重線、全幅・半幅・短い線を選択できます。
- 作品集エディターに「＋ 区切り線」を追加。配置を変更でき、作品集Preview・読み込み時の閲覧画面に反映されます。
- 作品集を単一作品として読み込む場合もDividerブロックとその設定を維持します。
- Cut/JoinではDividerを分割・結合しません。Shuffle/Reverseでは独立した単位として扱います。
